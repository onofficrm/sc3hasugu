# 온오프빌더 지역 랜딩페이지 자동 확장 가이드

지역 키워드(예: 송파구하수구막힘, 강남구하수구막힘) 기반의 랜딩페이지를 무한히 확장하면서도, 검색엔진의 중복 문서(Duplicate Content) 페널티를 최소화하기 위한 자동 템플릿 구조 설계입니다.

## 1. 지역 랜딩페이지 템플릿 구조 및 생성 플로우

온오프빌더 플러그인 관리자 메뉴에서 다음 순서로 랜딩페이지를 생성합니다.

1. **새 랜딩페이지 추가**: `새 지역 페이지 만들기` 클릭
2. **지역명 및 키워드 입력**: 타겟 지역(예: 송파구)과 메인 키워드 입력
3. **지역 동네명 입력**: 해당 구의 하위 동네 목록(쉼표 구분) 입력
4. **연락처 및 폼 설정**: 전화번호, 카카오톡 링크, 숏코드 매핑 (기존 페이지 설정 불러오기 지원)
5. **템플릿 및 문구 변형 선택**: 각 섹션별 문구 옵션(A/B/C 타입)을 선택하여 페이지 텍스트 조합
6. **자동 문구 생성 및 미리보기**: 변수가 치환된 전체 페이지 미리보기
7. **발행**: 고유 URL(Slug)로 퍼블리싱 완료

---

## 2. 변수 목록 (Merge Tags)

전체 템플릿에서 공통으로 사용되며, 페이지 렌더링 시 자동으로 치환되는 변수입니다.

- `{{REGION}}` : 지역명 (예: 송파구)
- `{{MAIN_KEYWORD}}` : 대표 키워드 (예: 송파구하수구막힘)
- `{{SINK_KEYWORD}}` : 싱크대 키워드 (예: 송파구 싱크대 막힘)
- `{{TOILET_KEYWORD}}` : 변기 키워드 (예: 송파구 변기 막힘)
- `{{DRAIN_KEYWORD}}` : 배수구 키워드 (예: 송파구 배수구 막힘)
- `{{BACKFLOW_KEYWORD}}` : 역류 키워드 (예: 송파구 하수구 역류)
- `{{COMPANY_NAME}}` : 업체명 (예: 온오프배관)
- `{{PHONE_NUMBER}}` : 링크용 전화번호 (예: 01012345678)
- `{{PHONE_DISPLAY}}` : 화면 표시용 전화번호 (예: 010-1234-5678)
- `{{KAKAO_LINK}}` : 카카오톡 링크 (예: https://pf.kakao.com/...)
- `{{CONTACT_FORM_SHORTCODE}}` : 문의폼 숏코드
- `{{SERVICE_AREAS}}` : 지역명(동네) 태그 목록
- `{{PAGE_SLUG}}` : URL Slug (예: songpa-drain-clog)

---

## 3. 관리자 입력 필드 구조

관리자 화면에서는 최소한의 정보만 입력하면 나머지는 자동 완성되도록 구성합니다.

- **[공통 설정 불러오기] 버튼**: 기존 설정(전화번호, 카톡링크, 업체명 등)을 그대로 가져옴
- **기본 정보 설정**:
  - 타겟 지역 (예: 송파구)
  - 하위 동네 리스트 (예: 잠실동, 석촌동, 가락동...)
  - URL Slug (자동 생성: 지역명 영문 변환 또는 수동 입력)
- **키워드 자동 생성 룰**: 
  - 입력한 `{{REGION}}`을 바탕으로 `{{REGION}} + 하수구막힘` 공식으로 메인 및 서브 키워드 자동 세팅 (수동 수정 지원)
- **콘텐츠 변형(Variation) 선택기**:
  - 헤드라인 톤앤매너: [A타입: 직관형] / [B타입: 문제해결형] / [C타입: 지역강조형]
  - 서브 헤드라인 방식: [A타입] / [B타입] / [C타입]
  - CTA 버튼 문구 세트: [A타입] / [B타입] / [C타입]

---

## 4. 중복 콘텐츠 방지를 위한 섹션별 자동 치환 문구 예시 (옵션 3가지)

동일한 HTML 구조에 지역명만 바뀌면 구글 검색엔진에서 중복 문서로 간주할 수 있습니다. 이를 방지하기 위해 섹션별로 3가지의 텍스트 옵션을 제공하여 믹스 앤 매치(Mix & Match)합니다.

### 4-1. H1 (메인 헤드라인)
- **Type A (직관형):** `{{MAIN_KEYWORD}}, 지금 바로 상담하세요`
- **Type B (문제해결형):** `답답한 {{REGION}} 배관 문제, {{MAIN_KEYWORD}} 전문 해결`
- **Type C (지역강조형):** `{{REGION}} 전지역 신속 출동 대기, 확실하게 뚫어드립니다`

### 4-2. H2 (서브 헤드라인: 증상 섹션)
- **Type A:** `이런 증상이 있다면 {{REGION}} 하수구 막힘 점검이 필요합니다`
- **Type B:** `{{REGION}} 주민들이 자주 겪는 배관 막힘 증상 TOP 8`
- **Type C:** `단순 막힘일까? {{REGION}} 배관 역류 전조증상 확인하기`

### 4-3. 지역 SEO 문구 (CTA 상단)
- **Type A:** `{{REGION}} 내 주거지역, 상가, 사무실, 음식점 등 다양한 현장 상담이 가능합니다.`
- **Type B:** `아파트, 빌라, 상가 등 {{REGION}} 지역 특성에 맞는 맞춤형 배관 점검을 진행합니다.`
- **Type C:** `{{REGION}} 전지역 당일 방문! 거주하시는 동네를 확인하시고 바로 문의주세요.`

### 4-4. CTA 버튼 문구
- **Type A:** `지금 전화상담` / `막힘 증상 확인하기`
- **Type B:** `{{REGION}} 담당자 연결` / `배관 문제 알아보기`
- **Type C:** `긴급 출동 요청` / `작업 과정 살펴보기`

### 4-5. 서비스 카드 제목 및 설명
- **제목:** `{{SINK_KEYWORD}}`, `{{TOILET_KEYWORD}}`, `{{DRAIN_KEYWORD}}`, `{{BACKFLOW_KEYWORD}}`
- **설명:** `{{REGION}} 내 음식물 찌꺼기나 기름때로 인한 싱크대 역류 증상을 꼼꼼히 점검해드립니다.`

## 5. SEO 자동 생성 규칙

SEO 메타 데이터도 입력된 변수와 지역명에 맞춰 자동 생성됩니다.

- **SEO Title (공식):** 
  - `{{MAIN_KEYWORD}} | 싱크대·변기·배수구·하수구역류 상담`
- **Meta Description (공식):** 
  - `{{MAIN_KEYWORD}} 상담 페이지입니다. {{SINK_KEYWORD}}, {{TOILET_KEYWORD}}, {{DRAIN_KEYWORD}}, {{BACKFLOW_KEYWORD}} 등 {{REGION}} 지역 배관 문제를 빠르게 상담해드립니다.`
- **URL Slug:** 
  - `{region-in-english}-drain-clog` (예: `songpa-drain-clog`)
- **Schema Markup (JSON-LD):** 
  - `addressLocality` 필드에 `{{REGION}}` 자동 삽입.
  - `itemOffered` 필드에 `{{MAIN_KEYWORD}} 상담` 삽입.
- **Open Graph 제목/설명:**
  - SEO Title 및 Meta Description과 동일하게 자동 상속 처리.

## 6. FAQ 자동 생성 규칙

지역 키워드가 섞인 FAQ 세트를 제공하여 자연스러운 롱테일 키워드 쿼리 노출을 유도합니다. 관리자에서 문구를 추가 편집할 수 있습니다.

1. **질문:** `Q. {{REGION}} 전지역 상담 및 출동이 가능한가요?`
   **답변:** `A. 네, {{SERVICE_AREAS}} 등 {{REGION}} 전역 어디든 원활한 상담과 방문 점검 안내가 가능합니다.`
2. **질문:** `Q. {{SINK_KEYWORD}} 비용은 어떻게 되나요?`
   **답변:** `A. 배관 구조와 이물질 종류에 따라 다릅니다. {{REGION}} 현장 상황에 맞춰 상세히 안내해드립니다.`
3. **질문:** `Q. {{TOILET_KEYWORD}} 작업에 시간이 얼마나 걸리나요?`
   **답변:** `A. 단순 막힘은 금방 끝나지만, 메인 배관 문제일 경우 시간이 더 소요될 수 있습니다. 꼼꼼하게 원인을 파악합니다.`

---

## 7. 이미지 Alt 텍스트 자동 생성 규칙

이미지 `alt` 속성에도 치환 변수를 투입하여 구글 이미지 검색 노출 및 웹 접근성을 향상시킵니다.

- **메인 히어로 이미지:** `{{MAIN_KEYWORD}} 전문 장비 출동 상담`
- **증상 카드 (싱크대 아이콘):** `{{SINK_KEYWORD}} 배관 점검`
- **증상 카드 (변기 아이콘):** `{{TOILET_KEYWORD}} 상담 현장`
- **서비스 카드 (배수구 아이콘):** `{{DRAIN_KEYWORD}} 역류 및 악취 제거`
- **장비 소개 섹션 이미지:** `{{REGION}} 배관 내시경 및 고압세척 장비 작업`

## 8. 지역명 태그 출력 방식

관리자가 쉼표로 구분하여 입력한 동네 리스트 문자열을 배열로 분리한 후, HTML 템플릿 렌더링 단계에서 루프를 돌며 뱃지(Tag) UI로 렌더링합니다.

**관리자 입력값:** `잠실동, 석촌동, 가락동, 문정동`

**서버 단 렌더링 코드 (PHP):**
```php
$areas = explode(',', $settings['service_areas']);
$tags_html = '';
foreach($areas as $area) {
    $tags_html .= '<span class="ob-drain-tag">' . esc_html(trim($area)) . '</span>';
}
// 템플릿의 {{SERVICE_AREAS}}를 $tags_html로 치환
```

**출력 HTML:**
```html
<div class="ob-drain-tags-wrap">
  <span class="ob-drain-tag">잠실동</span>
  <span class="ob-drain-tag">석촌동</span>
  <span class="ob-drain-tag">가락동</span>
  <span class="ob-drain-tag">문정동</span>
</div>
```

## 9. 다른 지역으로 복제(Duplicate)하는 방법

플러그인 내 **"새 지역 복제하기(Clone to New Region)"** 기능을 통해 수십 개의 지역 페이지를 1분 안에 자동 생성합니다.

1. **원본 페이지 선택**: 복제할 베이스 페이지(예: 강동구) 선택 후 `지역 복제` 버튼 클릭
2. **지역 변수 팝업 입력**: 
   - 새 타겟 지역명 (예: `송파구`)
   - 새 동네 리스트 (예: `잠실동, 석촌동, 가락동, 문정동...`)
3. **자동 치환 및 저장**: 
   - 기존의 `wp_options` 데이터 구조를 복사.
   - 내부 데이터 중 문자열 `강동구`를 `송파구`로 일괄 `str_replace` 처리.
   - 새로운 슬러그(`songpa-drain-clog`)로 식별자를 변경하여 저장 완료.
4. **옵션 변형 및 발행**: 복제된 페이지 설정에 진입하여 문구 타입(A/B/C)을 다르게 변경 후 최종 발행.

## 10. 중복 콘텐츠를 줄이기 위한 문구 변형 방법 (도어웨이 페이지 페널티 회피 전략)

구글은 동일한 레이아웃과 텍스트에 지역명만 기계적으로 바꾼 페이지들을 "Doorway Pages(도어웨이 페이지)"로 간주하여 검색 순위에서 누락시킬 수 있습니다. 이를 우회하기 위해 다음 기법을 지원합니다.

1. **섹션 믹스 앤 매치 (Mix & Match):** 
   - 헤드라인 3종, 서브제목 3종, CTA 3종 세트를 지원하여 페이지를 섞습니다.
   - [A지역 = 헤더A+서브B+CTA C], [B지역 = 헤더C+서브A+CTA B] 형식으로 조합하면 페이지 간 텍스트 유사도가 크게 낮아집니다.
2. **동적 텍스트 밀도 변화 활용:**
   - 본문에 억지로 키워드를 스터핑하는 대신, `{{SERVICE_AREAS}}` (동네 리스트)의 텍스트 양이 지역마다 크게 다르다는 점을 활용합니다. 특정 구역에 고유 단어가 대량으로 삽입되면서 단어 분포도(TF-IDF)가 자연스럽게 차별화됩니다.
3. **서비스 항목 셔플 (Shuffle) 기능:**
   - 서비스 카드 6개(싱크대, 변기, 배수구 등)의 출력 순서를 관리자 단에서 드래그 앤 드롭으로 지역마다 다르게 섞을 수 있도록 설계합니다. HTML DOM 구조가 변경되어 로봇이 다른 페이지로 인식하는 데 도움을 줍니다.
4. **커스텀 이미지 필드 지원:**
   - 템플릿 메인 이미지는 공통으로 쓰되, 지역마다 다른 썸네일이나 대표 현장 사진을 1~2장 교체하여 올릴 수 있게 허용합니다. (이미지 해시 차별화)
