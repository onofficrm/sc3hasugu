# “강동구하수구막힘” 랜딩페이지 최종 검수(QA) 리포트

온오프빌더 플러그인 환경에 맞춰 제작된 "강동구하수구막힘" 랜딩페이지의 최종 QA 결과 및 배포 가이드입니다. 

---

## 1. 수정이 필요한 항목 (워드프레스 특화 이슈)
- **관리자 바(Admin Bar) 겹침 이슈**: 워드프레스 로그인 상태에서 상단 고정 헤더(`position: sticky; top: 0;`)가 워드프레스 관리자 바(Admin Bar)에 가려질 수 있습니다. `body.admin-bar .ob-drain-header { top: 32px; }` (모바일은 46px) CSS 추가 보완이 필요할 수 있습니다.
- **이미지 URL 경로**: HTML 내 임시로 삽입된 Unsplash 이미지 경로를 실제 업로드된 고화질/최적화된 미디어 라이브러리 경로(변수 치환 등)로 교체해야 합니다.

## 2. 바로 배포 가능한 항목
- **레이아웃 및 스코핑**: `.ob-drain-landing` wrapper와 모든 `.ob-drain-` 접두사 클래스 적용으로 테마(Elementor, Gutenberg 등)와의 CSS 충돌 방지 구조가 완벽히 적용되었습니다.
- **HTML 구조 및 반응형**: PC(그리드 2열~4열)부터 태블릿, 모바일(1열 정렬)까지 브레이크포인트(`1024px`, `768px`)에 맞춘 자연스러운 레이아웃 변환이 준비되었습니다.
- **FAQ 아코디언 JS**: 바닐라 JS로 작성되어 jQuery 충돌 없이 가볍고 정상적으로 작동합니다.
- **문의폼 UI**: 숏코드(`{{CONTACT_FORM_SHORTCODE}}`)가 없을 때를 대비한 Fallback UI와 실제 숏코드 렌더링 영역이 성공적으로 구축되었습니다.

## 3. SEO 보완이 필요한 항목
- **이미지 Alt 텍스트 실데이터 적용**: 현재 HTML 상에는 하드코딩된 예시 텍스트가 들어가 있습니다. `{{MAIN_KEYWORD}}` 등의 변수를 활용해 Alt 텍스트도 동적으로 치환되게끔 백엔드 스크립트를 연결해야 합니다.
- **Schema Markup 동적 바인딩**: 안내된 JSON-LD 코드가 `<head>` 영역이나 페이지 하단에 실제로 출력되도록 플러그인 렌더링 함수에 주입(Injection)하는 작업이 필요합니다.

## 4. 모바일 보완이 필요한 항목
- **하단 여백 완벽 확보**: 모바일 하단 고정 바(70px)를 위해 래퍼에 `padding-bottom: 70px;`를 적용했습니다. 단, 테마에 따라 푸터(Footer) 영역이 랜딩페이지 래퍼 바깥에 있을 경우 푸터 일부가 가려질 수 있으므로 배포 테마 환경에 맞춘 테스트가 한 번 더 필요합니다.
- **모바일 브라우저 주소창 고려**: 모바일 브라우저(크롬, 사파리 등)의 하단 네비게이션 바가 스크롤 시 생겼다 사라지는 현상(vh 이슈)에 하단 고정 CTA가 자연스럽게 따라오는지 실기기 테스트가 필요합니다.

## 5. CTA 보완이 필요한 항목
- **데이터 추적(Data-CTA) 확인**: 구글 애널리틱스(GA4) 이벤트를 수집하기 위한 `data-cta="..."` 속성이 모든 버튼에 성공적으로 부착되었습니다. 단, 배포 후 구글 태그 매니저(GTM)에서 해당 `data-cta` 속성을 트리거로 잡는 세팅을 완료해야 실제 추적이 시작됩니다.
- **전화번호 프로토콜**: `href="tel:{{PHONE_NUMBER}}"` 형식 적용 완료. 단, 숫자가 아닌 기호(하이픈 등)가 들어가지 않도록 플러그인 저장단에서 `preg_replace` 처리가 확실히 연동되었는지 점검해야 합니다.

## 6. 최종 배포 전 체크리스트
- [ ] 치환 변수(`{{COMPANY_NAME}}`, `{{PHONE_NUMBER}}`, `{{REGION}}` 등)가 백엔드에서 정상적으로 데이터 바인딩 되는가?
- [ ] Contact Form 7 또는 WPForms 숏코드가 페이지 내에서 정상적으로 폼 UI로 파싱되어 렌더링 되는가?
- [ ] 폼 제출 시 관리자 이메일로 정상적으로 알림이 들어오고, 성공 메시지가 출력되는가?
- [ ] 워드프레스 테마 커스터마이저에서 제공하는 전역 타이포그래피 설정과 플러그인의 폰트가 충돌하거나 깨지지 않는가?
- [ ] Cache 플러그인(LiteSpeed, WP Rocket 등)을 켠 상태에서도 모바일 하단 바와 아코디언 JS가 정상 동작하는가?

## 7. 배포 후 확인해야 할 항목
- **GA4 및 GTM 이벤트 유입 확인**: 사용자가 실제 모바일 기기에서 하단 고정 전화버튼 및 카카오톡 버튼을 눌렀을 때 이벤트 수집이 누락 없이 찍히는지 실시간 보고서 확인.
- **Google Search Console 등록**: 배포된 슬러그(`gangdong-drain-clog`)의 URL 검사 및 색인 생성 요청을 진행하고, 모바일 사용 편의성 오류가 발생하지 않는지 체크.
- **문의 전환 체크**: 실제 고객 입장에서 사이트에 접속해 스크롤을 내리며, 1~2번의 탭(Tap)만으로 전화 앱과 카카오톡 앱으로 자연스럽게 넘어가는지 실기기 테스트.
- **페이지 로딩 속도**: PageSpeed Insights를 통해 LCP(최대 콘텐츠 풀 페인트)가 2.5초 이내인지 확인. 용량이 큰 이미지가 있다면 WebP 포맷 변환 및 압축 플러그인(Smush 등) 적용.

> **총평:**  
> 현재 작성된 HTML/CSS/JS 및 데이터 구조는 "전환 최적화"와 "테마 독립성"을 완벽하게 갖추고 있습니다. 워드프레스 특유의 관리자 바 겹침이나 캐시 이슈만 실서버에서 가볍게 체크한다면 즉시 고효율 마케팅 랜딩페이지로 활용 및 확장이 가능합니다.
